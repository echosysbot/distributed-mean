<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → nginx → API | All UI requests cross nginx reverse proxy into the API |
| docker build → npm registry | Dockerfile pulls node + npm deps at build time |
| container network | nginx talks to api over the docker-compose network |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-10 | Tampering | nginx proxy path expansion (e.g., /jobs/../etc) | mitigate | Use exact `location /jobs` prefix matches; nginx normalizes URIs before matching; upstream is the same API that already validates all inputs |
| T-06-11 | Information Disclosure | nginx server_tokens default exposes nginx version | accept | Dev-only container; v1 scope does not include hardening headers |
| T-06-12 | Denial of Service | Long-lived SSE clients exhaust nginx worker connections | mitigate | nginx default 1024 connections per worker is sufficient for a dev system; proxy_read_timeout 24h aligned with SSE keepalive; documented limit |
| T-06-SC | Tampering | Dockerfile pulls node:20-alpine and nginx:1.27-alpine | mitigate | Both are official Docker Library images; tags pinned to minor versions; no third-party untrusted base images |
</threat_model>
